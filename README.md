# A Câmara

Site de portfólio de Pedro Maia. Tesouraria, dados e agentes de IA.

HTML, CSS e JavaScript puro. Sem framework, sem build, sem npm. Um `index.html`
mais uma pasta `assets/`, que é o que faz o deploy caber num comando e o preview
caber num duplo clique.

## O que tem aqui

| Caminho | O que é |
|---|---|
| `site/` | A página. É isto que vai para o ar. |
| `DESIGN-PACKAGE.md` | Todas as decisões criativas, escritas antes de qualquer geração. Paleta, tipografia, mapa de faixas do hero, copy literal de cada seção, camada vetorial, portão de copy. |
| `PLANO-DE-CONSTRUCAO.md` | A ordem de serviço em dez blocos, com portões e custos. |

`review/` não é versionado. É onde o vídeo cru e os frames de inspeção ficam, e
nada dali é publicado.
